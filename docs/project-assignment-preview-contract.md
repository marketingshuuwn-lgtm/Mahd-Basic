# عقد معاينة اعتماد المشروع

## الغرض

تسمح المعاينة للفريق باختيار نوع مشروع مقترح لعميل معروف في Trello، ثم رؤية أثر الربط المتوقع على بطاقاته قبل اعتماد القرار. المعاينة ليست إنشاءً لمشروع ولا كتابةً إلى Trello.

## المدخلات

يختار المستخدم عميلًا معروفًا من قراءة Board، مثل **سنام** أو **علامة تسويق**، ثم يختار نوعًا من أنماط العمل المعتمدة في Pilot: استراتيجية العلامة، تقويم تحريري وخطة محتوى، أو حملة إعلانية ترويجية.

## المخرجات

تعرض الشاشة عدد البطاقات المقروءة للعميل، نوع المشروع المقترح، حالة القرار، وقائمة البطاقات التي ستظهر ضمن المشروع في حال اعتماد القرار. كما تشرح أن Labels وقوائم Trello ستبقى كما هي.

| الحالة | السلوك |
|---|---|
| لا يوجد اختيار | يبقى زر المعاينة غير متاح. |
| تم اختيار نوع مشروع | يظهر زر «معاينة المطابقة قبل الاعتماد». |
| المعاينة مفتوحة | لا يوجد زر تنفيذ أو كتابة؛ القرار «بانتظار الاعتماد». |
| بعد الموافقة الفعلية | هذه المرحلة لا تنفذها؛ تحتاج بوابة موافقة مستقلة وتحديد مكان حفظ تعريف المشروع. |

## القيود

لا يستنتج النظام نوع المشروع من عنوان البطاقة أو قائمة Trello. لا ينشئ مشروعًا تلقائيًا، ولا يغير Label العميل، ولا ينقل أو ينسخ بطاقة، ولا يكتب في Trello. قرار الاعتماد يتطلب مراجعة مالك/مدير المشاريع ومدير الحساب.
