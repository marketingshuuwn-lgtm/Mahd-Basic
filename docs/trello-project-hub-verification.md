# تحقق Project Hub وViews الموحدة — Trello-only

## سياق التحقق

استخدم التطبيق اتصال Trello الموجود محليًا. أُجريت عمليات القراءة واختيار الـ Board فقط؛ لم يُنشأ Board أو Card ولم تُعدّل بطاقة خلال هذا التحقق.

## النتائج المؤكدة

| الاختبار | النتيجة |
|---|---|
| تحميل Project Hub | نجح؛ ظهرت 5 Boards متاحة كمشاريع Trello |
| المشروع النشط الأول | ظهر Board `PMO-Alaamaa` بوصفه المشروع النشط |
| اختيار مشروع من Hub | نجح؛ تغيير `مهام يومية - علامة` حمّل بطاقاته في مَهَد |
| توحيد الهوية | ظهر اسم المشروع النشط في شريط Views |
| Matrix بعد اختيار Board | حمل 162 بطاقة من Board المختار |
| Table View | عرض 162 صفًا من المصدر نفسه مع اسم القائمة، الحالة، الموعد والتقدم الفرعي |
| التنقل بين Views | Table وMatrix وCalendar وTimeline وGantt تظل ضمن Board النشط نفسه |

## ملاحظات مقصودة

- بعض البطاقات المغلقة أو المرتبطة بقوائم مغلقة تظهر باسم قائمة `غير معروفة` في Table، لأن تطبيق Trello-first يجلب القوائم المفتوحة فقط حاليًا. حالة البطاقة تظل محددة عبر `closed`.
- Project Hub لا يعرض عدادات بطاقات لكل Board، تفاديًا لقراءة بطاقات جميع المشاريع وتجاوز حدود Trello API.
- لا توجد بيانات مشروع داخل مَهَد خارج بيانات Board Trello في هذه النسخة.

## تحقق بعد إعادة التحميل

أُعيد تحميل التطبيق بعد إضافة Table View وتحسين قراءة القوائم. بقي المشروع النشط `مهام يومية - علامة` ظاهرًا، واستمر Table View في عرض 162 بطاقة من Board ذاته. كما بقيت القوائم المغلقة مستبعدة من اختيار القائمة الافتراضية للكتابة.

بعض قيم `غير معروفة` لا تزال ممكنة عندما لا يعيد Trello قائمة مرتبطة ببطاقة (مثل قائمة حذفت أو بطاقة فقدت مرجع القائمة)، وهي قيمة عرض احتياطية وليست تغييرًا في البطاقة.
