# عقد جسر Trello للـ Pilot — قراءة وتصنيف فقط

**الحالة:** معتمد للتنفيذ التجريبي.  
**النطاق:** Board واحد هو `Test - مهام اليوم`.
**الحد الفاصل:** لا ينشئ هذا الجسر بطاقات أو قوائم أو Labels، ولا ينقل أو يؤرشف أو يعدل أي بطاقة في Trello.

## المبدأ المعتمد

لا تختفي بطاقة من مَهَد بسبب عدم انتمائها إلى عميلَي Pilot. يقرأ الجسر كل بطاقة من Board ويصنفها في أحد المسارات التالية: **عميل**، أو **عمل داخلي تنظيمي**، أو **مكتبة قوالب**، أو **تحتاج مراجعة تصنيف**. لا يخمّن الجسر عميلًا أو مشروعًا من اسم البطاقة أو من List Trello.

| مصدر Trello | المسار في مَهَد | وضع المشروع |
|---|---|---|
| `THB - ثبات` | عميل: ثبات | يربط بمشروع Pilot المؤقت «تقويم تحريري وخطة محتوى». |
| `BRK - مزاد بركة` | عميل: مزاد بركة | يربط بمشروع Pilot المؤقت «استراتيجية العلامة». |
| `SNM - سنام` | عميل: سنام | يحتاج تعيين مشروع صريحًا. |
| `ALM - علامة تسويق` | عميل: علامة تسويق | يحتاج تعيين مشروع صريحًا. |
| `ALH - علامة الأم` | العمل الداخلي: علامة الأم | إداري وتنظيمي للشركة، وليس عميلًا. |
| قائمة `قوالب المهام` | المكتبة والقوالب | ليست مهام تنفيذية نشطة. |
| Label مفقود أو غير معرّف | مراجعة التصنيف | يبقى ظاهرًا ولا يعاد تصنيفه تلقائيًا. |

> **قاعدة Pilot المؤقتة:** Label العميل يحدد العميل أو العمل الداخلي فقط. يربط الجسر ثبات ومزاد بركة بمشروعهما الحالي لأن لكل منهما مشروع Pilot واحدًا معتمدًا. لا تسري هذه القاعدة على سنام أو علامة تسويق، ولا تسري عندما يفتح للعميل مشروع ثانٍ.

## نواتج التصنيف

| النتيجة | شرطها | ماذا تعرض مَهَد؟ | ماذا تفعل في Trello؟ |
|---|---|---|---|
| عميل مع مشروع Pilot | Label ثبات أو مزاد بركة. | المهمة داخل العميل ومشروع Pilot، مع القائمة والموعد ورابط المصدر. | لا شيء. |
| عميل يحتاج مشروعًا | Label سنام أو علامة تسويق. | العميل وبطاقاته، مع حالة «يحتاج تعيين مشروع». | لا شيء. |
| عمل داخلي | Label علامة الأم. | مسار إداري وتنظيمي مستقل عن العملاء. | لا شيء. |
| قالب | البطاقة في قائمة قوالب المهام. | المكتبة والقوالب، لا التنفيذ النشط. | لا شيء. |
| مراجعة تصنيف | Label مفقود/غير معرّف أو أكثر من تصنيف معروف. | قائمة مراجعة دون إدخالها في عميل أو مشروع. | لا شيء. |

## واجهة المعاينة المطلوبة

يعرض القسم المستقبلي «مطابقة Trello» عدد البطاقات في كل مسار، وبطاقات العملاء، والعمل الداخلي، والقوالب، والعناصر غير المصنفة. كل بطاقة تعرض عنوانها وقائمة Trello وموعدها ومالكها عند توفرهما ورابط مصدرها. لا تسمي الشاشة «مزامنة» لأن Trello يبقى مصدر الحقيقة ولا تقع كتابة ثنائية الاتجاه.

## معايير قبول الجسر

يقبل الجسر للعرض إذا ظهرت كل بطاقة في أحد المسارات المذكورة أو ضمن مراجعة واضحة، ولم تدخل علامة الأم ضمن العملاء، ولم تخمّن المنصة مشروعًا لسنام أو علامة تسويق، وبقيت بطاقة القالب خارج التنفيذ، ولم يصدر التطبيق أي طلب POST أو PUT أو DELETE إلى Trello.
